# Code of Conduct

SoundTap follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be patient with people who are new to flashing firmware, criticise
ideas and code rather than people, and accept that "no" is an answer. Harassment, insults and
personal attacks are not tolerated in issues, pull requests, discussions or anywhere else this
project lives.

Report unacceptable behaviour privately to a maintainer.
Reports are handled confidentially. Maintainers may remove comments, lock threads and block
accounts that break these rules.
